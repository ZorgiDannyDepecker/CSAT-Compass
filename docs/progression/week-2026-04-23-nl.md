## DEEL 1: RETROSPECTIEF — 23 april 2026

### 1. Executive Summary

Een hersteldag na een kritieke app-storing. Door een defecte `insert_edit_into_file`-operatie in
de vorige sessie waren alle functies in `app.py` na `_tab_hospitals` verwijderd, inclusief
`main()`. De app was compleet onbruikbaar.

Na systematisch herstel (hybride samenvoeging van huidige code + git-referentie), 250+ encoding
fixes en een reeks UI-verbeteringen is de codebase gestabiliseerd op versie **v0.8.0**. De
GitHub CI draait correct op Python 3.11/3.12/3.13.

---

### 2. Wat is er gedaan?

#### 2.1 Crash recovery — NameError: name 'main' is not defined

- Oorzaak: vorige sessie had alle functies ná `_tab_hospitals` verwijderd
  (`render_kpi_targets`, `_tab_targets`, `_build_issue_type_chart`, `_build_priority_chart`,
  `_render_feedback_themas`, `render_tab_tickets_prioriteit`, `_render_coming_soon`, `main`)
- Herstelstrategie: lijnen 1–2870 van de beschadigde file (verbeteringen behouden) +
  git v0.7.25 voor de ontbrekende functies

#### 2.2 Bug fix — TypeError in _tab_response

- `sum(_tk for _, _tk in _pil_map.values())` → `sum(_pil_map.values())`
- `score_pillar_breakdown` is `dict[int, dict[str, int]]` — waarden zijn integers, geen tuples

#### 2.3 Encoding fixes — 250+ CP437-corrupties

| Categorie | Aantal | Voorbeelden |
|---|---|---|
| Sectiecommentaar (`─`) | 83× | `ΓöÇ` → `─` |
| Accenten FR/NL | 28× | `├⌐` → `é`, `├┤` → `ô` |
| Emojis | 15× | `≡ƒÄ»` → 🎯, `ΓÜá` → ⚠️ |
| Stray chars na emojis | 6× | `📊è` → `📊`, `📋í` → 🟡 |
| Symbolen/overige | 12× | `Γëñ` → `≥`, `Γü░` → `⁰` |

#### 2.4 UI-verfijning

| Wijziging | Detail |

| Page icon | `💬¡` (corrupt) → `🧭` (CSAT-Compass kompas) |
